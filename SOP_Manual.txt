--------------------------------------------------------------------------------
💡 第一章：🚀 系統一鍵啟動與對齊（預儲程序 Stored Procedure）
--------------------------------------------------------------------------------
我們將「API掃描、進程清理、常駐守護啟動、健康檢測、指揮引擎拉起」整合為一鍵腳本，您不需再開啟多個視窗！

► 步驟與指令：
   1. 打開 Windows PowerShell 終端機。
   2. 輸入並執行以下一鍵啟動指令：
      powershell.exe -ExecutionPolicy Bypass -File C:\Genesis\Genesis_Stored_Procedure.ps1
   3. 腳本會自動完成：
      - 重新掃描並更新地端 API 規格，同步至雲端知識庫。
      - 檢查開發執行模式是否安全鎖定於 LOCAL 模式。
      - 清理地端掛掉的殘留進程。
      - 背景拉起 Startup Manager V4。
      - 進行健康檢查並印出志玲的健康診斷報告。
      - 自動打開指揮中樞 Main Engine 互動控制台！

► 桌面一鍵啟動設定：
   - 可以在桌面新增捷徑，對象輸入上述 powershell 啟動指令，以後雙擊桌面捷徑即可一鍵完成系統對齊與啟動！

--------------------------------------------------------------------------------
💡 第二章：⚙️ 開發節流模式切換（防範雲端 API 鎖定）
--------------------------------------------------------------------------------
若要在 AG 上盡情開發新產品而不被 Google 鎖定 API，請確保系統鎖定在地端 RTX 3060 運算。

► 模式修改步驟：
   1. 用文字編輯器打開設定檔： C:\Genesis\Config\telegram_config.json
   2. 尋找 "development_mode" 參數：
      - 「地端優先開發模式（極力推薦）」：設為 "LOCAL"
        "development_mode": "LOCAL"
        ※ 在此模式下，所有寫入代碼、語意解析指令 100% 強制在地端 RTX 3060 跑 Ollama (Qwen2.5-Coder)，消耗 0 雲端 API 額度！
      - 「雲地混合生產模式」：設為 "HYBRID"
        "development_mode": "HYBRID"
        ※ 此模式會優先以地端執行，若地端失效則自動 Failover 至雲端 Gemini Pro。

--------------------------------------------------------------------------------
💡 第三章：🛡️ 剛性自癒與編譯檢查（TDD 防幻覺防禦）
--------------------------------------------------------------------------------
系統已全面部署語法檢查與 TDD 驗證，當 AI 生成有語法錯誤的程式碼時，地端會自動拒收並引導修復。

► 運作流程：
   1. 您在 Telegram 或儀表板發起代碼生成指令。
   2. 地端背景進程（Sync_Daemon）寫入檔案後，會自動執行 `py_compile` 編譯檢查。
   - 【檢查通過】：繼續執行並同步 Hash 到資料庫。
   - 【檢查失敗】：直接將任務狀態設為 FAILED，阻止錯誤檔案損毀系統，並將報錯 Traceback 寫入 C:\Genesis\Log\Error.log。
   3. 當發現任務失敗時，可在對話框輸入 `/doctor`，系統會啟動自癒模組讀取 Error.log，自動修復該代碼，完全不需手動 debug！

--------------------------------------------------------------------------------
💡 第四章：👑 萬用技能與子代理人調度（一人公司協同運轉）
--------------------------------------------------------------------------------
目前地端 6 大子代理人（PM、SCM、RD、QA、MFG、Sales）已與萬用產生器主引擎（Skill_02.py）完美接通，並導入了「毫秒級剪枝掃描」，運行只需幾毫秒！

► 執行步驟：
   1. 確保已透過第一章的 Stored Procedure 腳本進入 Main Engine 控制台。
   2. 在控制台對話框中輸入：
      啟動 02
   3. 系統將會循序喚醒：
      - Diag_Agent.py (PM 需求盤點)
      - Security_Agent.py (SCM 安全稽核)
      - Compiler_Agent.py (RD 資源編譯)
      - Tester_Agent.py (QA 剛性校驗，自動吐出品質代碼 0xFC09)
      - Sync_Agent.py (MFG 部署生產)
      - Analyst_Agent.py (Sales 營運數據分析)
   4. 運行結束後，所有子代理人的執行日誌與 SHA-256 哈希值將會自動寫入不可篡改的 Genesis_History.db 中，達成營運閉環！

--------------------------------------------------------------------------------
💡 第五章：📁 RAG 接地知識庫更新
--------------------------------------------------------------------------------
為防止雲端 AI 因為不知道地端 API 而胡亂幻想，請在每次 SDK 介面有大變動時手動對齊規格。

► 對齊指令：
   1. 打開終端機，執行規格掃描器：
      python C:\Genesis\RD_Center\SDK\System\Generate_API_Specs.py
   2. 腳本會自動抓取所有 Python 積木的參數定義與 Class Docstrings，生成 sdk_api_reference.md 並拷貝至您的 Google Drive 知識庫，讓雲端指揮所即時接地！
